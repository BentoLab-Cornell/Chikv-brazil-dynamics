# Data and generated-file inventory

The repository contains the following input files. Their presence does not establish how the files were prepared or when the original data were downloaded.

## Included source files

| Location | Files | Use in the revised paper |
|---|---|---|
| `chikungunya/` | 12 DBC files, `CHIKBR15.dbc` through `CHIKBR26.dbc` | 2016–2025 files feed the primary import; 2026 is separate temporal evaluation; 2015 is retained but excluded from the revised study window |
| `population/` | 11 CSVs, `ibge_pop_age_2015_clean.csv` through `ibge_pop_age_2025_clean.csv` | Module 02 reads 2016–2025; 2015 is retained outside the current panel |
| `zika/` | `zikadata.zip` | Historical archive; not an input to the revised primary chikungunya model |

The population CSVs contain a municipality identifier/name column, age columns from under 1 year through 79 years, an open-ended 80+ category, and `Total`. Module 02 reads the files as Latin-1. Do not overwrite these source files with generated panels.

The surveillance files come from SINAN/DATASUS. The 2016–2025 population inputs were verified against the 2000–2025 RIPSA municipality population estimates by age and sex distributed through DATASUS TabNet. See the [population input notes](../population/README.md#source-and-preparation) for the source table, verification, and alignment to the fixed 2020 municipality geography.

### Production residence panel

Seneca job 239791 on 28 October 2026 used 668,400 municipality-month rows and 1,215,063 cases. The study retained 1,215,074 confirmed notifications before the municipality join. Federal District residence codes in the `5399xx` series were mapped to Brasília (`530010`), retaining 23 cases. Eleven records remained unmatched under the fixed 2020 geography. Seven had missing or zero residence codes, two had code `330000`, and two had code `510183` (Boa Esperança do Norte, added in 2025).

The previous Module 06 notebook rebuilt the panel from the original residence codes and reported 1,215,040 cases. Module 06 now uses the panel archived with the production fit in its original row order. The Figure 3B regional summaries were reproduced from this panel and fit. The earlier Figure 5 evaluation count of 325,928 cases omitted four reassigned Brasília cases with onset in 2024–2025. The harmonized evaluation denominator is 325,932. The exact strategy-level outputs from the figure's original scoring archive remain to be reconciled.

## Missing production evidence

The repository does not include the complete primary/sensitivity fit archive, rolling predictions, longer-horizon output bundle, production environment lockfile or HPC logs. A production manifest should identify the generating code, input checksums, model settings, municipality ordering, source versions and matching outputs.

Keep input versions fixed when comparing against the submitted results, particularly the partial-2026 snapshot, annual population files and municipality definitions.
